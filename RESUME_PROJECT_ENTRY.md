# Resume-ready project entry

**TaskFlow — Full-Stack Task Management Platform**  
*Angular, JavaScript/TypeScript, Node.js, Express.js, Python, Flask, Docker, AWS ECS/Fargate (deployment-ready)*

- Built a responsive task management web app with task creation, editing, deletion, priority/status tracking, search, and status filters using Angular.
- Developed RESTful APIs in Node.js and Express.js with validation and persistent demo storage; connected the UI to the API through HTTP services.
- Implemented a Python Flask analytics microservice to calculate task-status totals, priority distribution, and completion rate, with a fallback summary in the Node API.
- Containerized the frontend, backend, and analytics service with Docker Compose and documented an AWS ECS/Fargate deployment path.
